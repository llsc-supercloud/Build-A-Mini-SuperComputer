
# Software application and libraries 

In the first section of this course we focused on system configurations to 
stand up the mini-cluster with a network, shared filesystem and resource 
manager.

Now that we have a system, we need to install the standard libraries and tools
that users expect on a supercomputing system. 

In this section you will find sub-diretories for each of the standard software 
tools and libraries.  In each case we have done our best to provide you with 
the approximate amount of time it takes to build or install the library.  
Unless stated otherwise, these tools and libraries can be installed in any order.
