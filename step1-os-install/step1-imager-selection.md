## Getting the Correct Version of Raspberry Pi Imager

The cluster built with this set of instructions has been tested and confirmed for RaspberryPi Imager v1.9.6 
NOTE: The newest Imager versions (2.0) are designed to simplify the installation of the operating system for a single Raspberry Pi where it is assumed that the user needs wifi to be operational on the system. The steps required to disable wifi on the compute nodes make it difficult to use a newer version of the RaspberryPi imager, thus the choice of v1.9.6
To get a copy of Imager v1.9.6 you will need to go to the Git Repo and do a bit of searching.

1. Go to: https://github.com/raspberrypi/rpi-imager/releases
2.  Scroll down until you find: 1.9.6
3. At the bottom of that block you will see: Assets
4. Download the file that matches the OS on your laptop
5. Install the imager
