
# Configuring Resource Manager

Supercomputers use resource managers to insure that the appropriate resources are available for a job prior 
to starting the job on the system. Resource Managers are necessary because the range of application types, the 
number of users and jobs can lead to oversubscription of compute nodes unless there is a service monitoring and 
managing the system workload. 

For this course we are using the Slurm scheduler and this section of the repository walks you through the 
steps required to configure and test your scheduler configuration.
